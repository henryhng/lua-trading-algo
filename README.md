Automated Lua helper for Roblox's Trade Tower game.
- Automated currency clicker, using an algorithm to decide what to keep or sell based on current demand
- Automated click upgrades and case purchases within a chosen price range
- Adaptive marketplace algorithm, selling items under a configured limit and reading item values with recent averages to capture deals
- Automated buy/sell algorithm with a value/percentage range for a given item
- Jackpot mechanism: sum solver that provides 1) an exhaustive search and 2) a greedy search to identify items in least-demand to enter

While I no longer maintain this software (have not in five years), I strongly believe that this week-long project greatly developed my passion for computation and algorithms.
